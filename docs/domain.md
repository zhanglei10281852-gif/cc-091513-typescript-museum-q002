# 领域说明

野外采集受许可证的物种范围、地理边界、数量配额和有效期约束。现场采集、移动端补传、经手交接与入馆时间可能不同，记录需要区分事件发生顺序和接收顺序。

`reference/domain.json` 保存公开的许可状态、采集事件和交接类型枚举。正式业务记录应使用稳定标识，并保留许可证版本、设备事件号和原始证据。

## 账册模型

- **许可证**（`Permit`）：版本化。每次修订产生新版本（物种范围、地理边界、配额、有效期、编号均可变更），旧版本与旧编号保留在案用于识别陈旧引用。状态机：draft → active ⇄ suspended →（expired 由有效期推导）→ revoked（终态）。
- **采集记录**（`CollectionRecord`）：以 `deviceId + deviceEventNo` 幂等入账；`occurredAt`（事件发生时间）参与许可校验，`receivedAt`（接收时间）记录入账顺序。`observed` 不占用配额，`collected` 占用。
- **配额流水**（`QuotaMovement`）：hold（占用）→ confirm（入馆转实占）；release 对应复核驳回、野外放归、重复合并。剩余额度 = 限额 − 占用 − 实占。隔离中的记录预占配额，防止复核期间超采。
- **隔离复核**（`QuarantineCase`）：凡物种越界、坐标越界、超有效期、许可证未生效 / 暂扣 / 撤回后采集、配额不足、编号陈旧或无法识别的记录，先入隔离，由馆方按当前许可版本复核，结论留痕。
- **重复候选**（`DuplicateGroup`）：同一野外编号出现在多条有效记录上即成组；处理结论为合并（正本保留）或确认为不同标本。
- **交接与入馆**（`CustodyHandoff` / `AccessionBatch`）：交接链从野外队或合作机构开始，环节必须连续；入馆要求链端到馆，入馆后配额转实占。
- **撤回语义**：revoke 只阻止撤回时点之后的采集，已形成的记录、照片、交接、入馆与配额流水全部保留，来源证据不可抹除。
- **敏感坐标**：物种范围内标记 `sensitive` 的物种，其精确坐标仅馆方与获授权研究人员可见，其余角色得到粗化坐标。
